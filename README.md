# North Lake office TV

A simple full-screen slideshow for the office TV's web browser. Built to work on older smart-TV browsers (no libraries, plain JavaScript).

- `slides.js`: the list of slides and how many seconds each one shows.
- `slides/`: 1920x1080 JPG slides.
- The page reloads itself every 15 minutes, so new slides show up on the TV automatically.

Public page: keep slides to things that are fine for anyone to see.
